# Merch shipping UI — September 22, 2026

The fulfillment page now opens on **Unshipped**, including new, exported and held orders. Shipped and All orders are explicit history views. The API and order-query defaults agree with the page.

## Design and interaction

Applied the project [UI designer guidance](ui-designer.md) and [Daisy Chain design skill](design-system/SKILL.md), with a separate design-context review. Existing colors, font roles and asymmetric radii remain the foundation; all new styles are scoped to `MerchDashboard.module.css`.

- Removed both crowded generic instructional paragraphs. Shipping procedures live in the [fulfillment SOP](https://github.com/daisychainsd/daisychain-ops/blob/main/SOP-merch-fulfillment.md).
- Replaced oversized pill navigation with quiet section tabs. Controls use body typography, consistent spacing and a single SVG select chevron. Native select keyboard behavior remains intact.
- Customer, address and purchased items lead each order card. Mark shipped is the primary action; tracking, notes and secondary metadata expand on demand.
- CSV actions appear only after selection. Re-export remains explicit. Export does not mean shipped.
- Payment, inventory, changed Bandcamp details and duplicate-label warnings stay visible on the affected order. Existing shipping guards and snapshot review still apply.
- An empty Unshipped queue offers View shipped orders. The count describes the current page, not a total across all history.
- Mobile cards stack without horizontal overflow. Main controls have 44px targets; labeled fields, focus outlines, pressed/current states and decorative SVG annotations support keyboard and assistive-technology use.

## Validation

The isolated Playwright harnesses cover Unshipped by default, shipped history, shipping toggles without tracking, CSV download/re-export, Bandcamp source filtering and corrected-address review, inventory retry behavior, product editing and desktop/mobile layouts. Fixture tests block external requests and never alter customer orders. See [browser instructions](tests/MERCH-BROWSER.md).

The September 22 production import checkpoint remains eight physical Bandcamp orders plus four website orders. This UI change does not infer shipping state or alter the imported records. Bandcamp deployment evidence is in [the activation record](BANDCAMP-ORDERS-2026-09-22.md). Deployment/check results for this UI change are recorded in its GitHub pull request.

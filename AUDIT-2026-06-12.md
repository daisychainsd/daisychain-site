## 📋 Still TODO (not addressed this pass — need a decision or infra)

- **Rate limiting** on `/api/newsletter`, `/api/laylo-subscribe`, `/api/convert`, `/api/checkout` — needs an infra choice (Vercel/Upstash). Currently anyone can mass-subscribe emails/phones or hammer the ffmpeg endpoint.
- **`/api/convert` auth + input size cap** — unauthenticated CPU-bound endpoint (DoS / bill amplification).
- **Signup existing-email / email-confirmation states** — Supabase returns success for an already-registered email → silent confusing redirect. Needs identities-length / null-session handling.
- **Buy-flow resume after login** — user who came to buy lands on `/account` instead of resuming the purchase.
- **Supabase server client typed non-null** (`server.ts` returns `null as unknown as …`) — should be `| null` and callers null-checked.
- **Accessibility** — focus traps + `role="dialog"`/Escape on `CartDrawer` and `LayloModal` (MobileNav is the good reference).
- **NewsMarquee default content is hardcoded + stale** ("JUN 5 — PLAYER DAVE") — move to CMS or refresh.
- **Sanity `liveEdit` lets editors publish incomplete docs** — every consumer must null-guard; consider tightening required fields on the riskiest ones.
- **Logged-in→account reconciliation** for guest purchases by email (groundwork laid via `buyerUserId`).
- **Resend domain verification** so guest download emails actually send.
- Minor: `TrackList` duplicate React keys; `DspRow` omits Bandcamp; physical order has no durable Supabase record if Shopify + alert both fail.
